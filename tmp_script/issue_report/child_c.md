## 背景

## 対応内容
- ブランチ規約に、コミット種別と対応する接頭辞の方針を追記する。
- 少なくとも `core/` を追記する。他の種別(`update/`、`refactor/` など)も追加するかを、この Issue で決める。
- 命名の基本形は `<接頭辞>/<Issue番号>-<英数字とハイフン>` とする(既存運用に合わせる)。
