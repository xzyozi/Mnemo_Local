親 Issue: #30

## 背景
`validate_docs.py`(#22、#28)に、文書の整合性を担保する検査を追加する。いずれも標準ライブラリのみで 1秒以内に終わる。

## 対応内容
| 検査 | 内容 | レベル(初版) |
| :-- | :-- | :-- |
| 本文の相対リンク切れ | `[text](相対パス)` のリンク先ファイルの実在(`#アンカー`・外部URLは対象外) | 警告 |
| 文書番号とファイル名の一致 | 形式文書で `document_number` とファイル名の番号が一致するか(ADR の既存命名 `001-…` は移行まで除外) | 警告 |
| ADR 番号の重複 | 同一 `document_number` が複数の ADR にないか | エラー |

## 設計上の注意
- #14 の「Markdown のリンク切れ検査」項目と重なる。本 Issue で `docs/` 配下を対象に実装し、#14 側は完了チェックに反映する。
- コードフェンス内(`mermaid` 含む)の `[...](...)` は誤検知を避けるため対象外にする。
- 検査ルールを変更する場合は、先に `docs/README.md` の規約を更新する(`doc_validation.md` の方針に従う)。

## 受け入れ条件
- [ ] 意図的に壊した入力(リンク切れ、番号不一致、ADR 重複)で、それぞれ検出される。
- [ ] 現行 `docs/` に対してエラー0件。
- [ ] `docs/setup/doc_validation.md` の検査項目表に追記されている。
- [ ] `docs/` 全体の検証時間が 1秒以内に収まる。
