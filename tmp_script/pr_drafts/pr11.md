タイトル: [core] ci.ymlに未検証の可視化・concurrency・timeoutを追加

## 概要
`ci.yml` が、プロジェクト固有の CI 契約(`.github/ci.sh` または Makefile の `ci`)が無い場合に何も検証せず成功扱いになる問題を改善します。

## 変更内容
- 契約が無い場合に `::warning::` と Job Summary で「未検証」を表示
- リポジトリ変数 `CI_REQUIRE_CONTRACT=true` で、契約なしを失敗に切り替え可能
- `concurrency` を追加(同一 ref の古い実行をキャンセル)
- `timeout-minutes: 30` を追加
- `push`(main / develop)トリガーを追加

## 影響
- このリポジトリには契約ファイルが無いため、`CI` ジョブに警告が表示されます(成功扱いは変わりません)。
- 既存の契約(`ci.sh` / Makefile)の実行条件は変更していません。

## 確認
- [ ] PR の `CI` で警告と Job Summary が表示される
- [ ] 連続 push で古い実行がキャンセルされる
- ローカルでは `git diff --check` のみ確認(ワークフローは未実行)
