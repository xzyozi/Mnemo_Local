タイトル: [update] Mermaid検証のpaths・バージョン一本化・フォールバックを改善

## 概要
`validate-mermaid.yml` と `validateMermaidMarkdown.mjs` の保守性と堅牢性を改善します。#13 のうち、小さく安全に直せる部分です。

## 変更内容
- `paths` にスクリプトとワークフロー自体を追加
- Mermaid CLI のバージョンを `env.MERMAID_CLI_VERSION`(yml)に一本化。mjs は環境変数から受け取る(未設定時はエラー)
- `github.event.*` を `env:` 経由に変更
- 比較元コミットが存在しない場合(force push など)は、警告を出して全件検証にフォールバック
- フェンス検出を CommonMark に寄せる(`~~~`、3個以上のフェンス)
- Puppeteer のブラウザキャッシュ(`~/.cache/puppeteer`)を追加
- `concurrency` と `timeout-minutes` を追加
- `docs/setup/mermaid_ci_validation.md` を更新

## 対象外(#13 に残す)
- ブロックごとの `npx` 起動の削減
- Puppeteer sandbox 対応(未発生)

## 注意
- ローカルに Node.js が無く、mjs とワークフローは未実行です。この PR の `Validate Mermaid diagrams` で初めて検証されます。
- ローカル実行には `MERMAID_CLI_VERSION` の指定が必要になりました(手順は `mermaid_ci_validation.md` を参照)。
